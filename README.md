# Adinath M C - Portfolio

A responsive, dynamic personal portfolio website built with **React**, **Tailwind CSS**, and **Framer Motion**.

## Overview
This repository contains the source code for my personal portfolio, showcasing my background as a Computer Science student, AI Enthusiast, and Backend Developer.

## Tech Stack
- Frontend: React.js
- Styling: Tailwind CSS
- Animations: Framer Motion
- Build Tool: Vite

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/adinathmc/react-tailwind-portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Design
Features a fully responsive dynamic layout optimizing space and scroll management across different devices.
